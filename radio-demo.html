Meet the callers

Each is the same engine at a different pitch & speed — tap to hear one line. In the real game these fire based on what you just did (evict someone → an angry caller rings in).

What you're hearing: the Web Speech API built into your browser — free, no downloads, and it reads live text, so talkback could react to your actual game forever. Quality is set by your device: modern iPhone/Mac (Siri voices) and Chrome/Edge sound good; older Androids can get properly robotic. There's no guaranteed NZ accent (Aussie's the closest) and it fudges te reo unless spelled out. The AM-crunch toggle lays static under the voice so the synthetic edge reads as “lo-fi radio” on purpose.
